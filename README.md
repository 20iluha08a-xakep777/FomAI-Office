# FomAI Office

**Единая рабочая среда: от документов до специализированных инструментов.**  
FomAI Office — это не просто набор веб-приложений, а полноценный офисный центр на стеке HTML/CSS/JS. В его основе лежит интегрированный пакет для работы с контентом (тексты, таблицы, презентации, PDF, графика), к которому подключаются узкоспециализированные модули для науки, творчества и автоматизации.

Проект изначально спроектирован под мобильные устройства (Mobile-first), но архитектура позволяет упаковать его в нативные приложения (APK, EXE, IPA).

## Ядро: Офисный пакет

Базовый функционал уже встроен в приложение и покрывает основные рабочие сценарии:

*   **Текстовый редактор (аналог Word)**: форматирование, стили, работа с абзацами и списками.
*   **Табличный процессор (аналог Excel)**: формулы, ячейки, базовые сводные данные.
*   **Презентации (аналог PowerPoint)**: слайды, шаблоны, управление порядком кадров.
*   **Графический редактор (аналог Paint)**: холст, кисти, фигуры, работа со слоями.
*   **PDF-модуль**: просмотр, аннотация и экспорт документов.

## Надстройки: Расширение рабочих возможностей

Модули в этом репозитории превращают обычный офис в универсальную платформу для разных профессий и хобби. Они подключаются к ядру, сохраняя единый стиль интерфейса.

### Для научной и учебной работы
Инструменты, которые экономят время при подготовке рефератов, курсовых и презентаций:
*   **Таблица Менделеева**: 118 элементов, свойства, интерактивные реакции — удобно вставлять данные прямо в документ.
*   **Астрономия и Химия**: справочники и карты для быстрого поиска фактов и иллюстраций.

### Для креатива и медиа внутри офиса
Инструменты для создания контента без выхода из рабочей среды:
*   **Музыкальные инструменты**: виртуальные пианино, гитара, барабаны — для записи идей или создания звукового фона к презентации.
*   **Вспомогательные утилиты**: метроном, тюнер, телесуфлёр — помогают при репетиции выступлений и записи видео.

### Планируемые инструменты для документооборота
В следующих версиях ядро офиса получит новые функции обработки файлов:
*   **Конвертеры**: преобразование PDF ↔ DOCX с максимальным сохранением структуры документа.
*   **Обработка изображений**: изменение размера, сжатие и базовая ретушь прямо в браузере перед вставкой в отчёт.

## Технологии и особенности ядра

Чтобы офис оставался быстрым даже на мобильных устройствах, мы используем легковесный стек:

*   **Стек**: HTML5, CSS3, Vanilla JavaScript.
*   **Хранение данных**: LocalStorage / IndexedDB (данные сохраняются локально, не нужен сервер).
*   **Функционал ядра**: undo/redo, автосохранение, контекстное меню, экспорт в PNG/JSON/HTML, проверка орфографии.
*   **Типографика**: поддержка ~130 шрифтов с кириллицей для профессионального оформления документов.

## Планы по сборке (Roadmap)

Архитектура ядра спроектирована так, чтобы офис можно было легко превратить в нативное приложение:

1.  **Android (APK)**: Сборка через Capacitor или Cordova для доступа к файловой системе телефона и камере.
2.  **Windows (EXE)**: Использование Tauri или Electron для работы с большими файлами и интеграции с ОС.
3.  **iOS (IPA)**: Публикация в App Store через Capacitor.

> **Важно:** Проект находится в активной разработке. Базовый офис уже функционален, а модули (особенно конвертеры) находятся в стадии реализации.

## Структура проекта

Такая структура позволяет легко добавлять новые модули, не ломая ядро офиса:

FomAI-Office/
├── index.html                # Точка входа. Общая оболочка офиса, навигация, сайдбар, область предпросмотра/редактора.
├── app.js                    # Роутер и состояние приложения. Переключает между режимами: «Документ», «Таблица», «Модуль».
├── style.css                 # Базовые стили: переменные (цвета тем), типографика (~130 шрифтов), адаптивная сетка, анимации переходов.
├── assets/                   # Статические ресурсы
│   ├── icons/                # Иконки для панели инструментов (Word, Excel, PDF, научные символы, ноты и т.д.)
│   ├── fonts/                # Папка со шрифтами (если не подключаются через CDN)
│   └── data/                 # Демо-данные: примеры документов, шаблоны презентаций, JSON-базы элементов (Менделеева, звёзд)
├── core/                     # Ядро офисного пакета (критическая логика)
│   ├── editor.js             # Логика текстового редактора (аналог Word): форматирование, стили, работа с абзацами.
│   ├── spreadsheet.js        # Логика табличного процессора (аналог Excel): ячейки, формулы, рендеринг сетки.
│   ├── pdf-engine.js         # Логика просмотра и аннотирования PDF (рендеринг страниц, выделение текста).
│   ├── storage.js            # Управление данными: автосохранение, undo/redo, работа с LocalStorage/IndexedDB.
│   └── utils.js              # Общие функции ядра: валидация, парсинг, обработка буфера обмена.
├── modules/                  # Подключаемые надстройки (то, что лежит в этом репозитории)
│   ├── science/              # Научные инструменты
│   │   ├── mendeleev.html    # Интерфейс таблицы Менделеева
│   │   ├── mendeleev.js      # Логика поиска элементов и реакций
│   │   ├── astronomy.html    # Карта звёздного неба
│   │   └── astronomy.js      # Логика навигации по созвездиям
│   ├── music/                # Музыкальные инструменты
│   │   ├── piano.html        # Интерфейс пианино
│   │   ├── piano.js          # Логика воспроизведения нот и записи
│   │   ├── guitar.html       # Интерфейс гитары с табулатурами
│   │   ├── drums.html        # Пэды и секвенсор барабанов
│   │   └── helpers.js        # Общий модуль для метронома, тюнера, телесуфлёра
│   └── utils/                # Планируемые утилиты (в разработке)
│       ├── converter.js      # Логика конвертации PDF ↔ DOCX (структура, стили)
│       └── image-tools.js    # Логика изменения размера и сжатия изображений
├── plugins/                  # (Опционально) Внешние интеграции
│   └── deepseek-api.js       # Модуль для отправки запросов к ИИ (если будет реализован)
└── docs/                     # Документация
    ├── README.md             # Этот файл
    ├── FEATURES.md           # Полный список всех функций и модулей
    └── BUILD.md              # Инструкция по сборке в APK/EXE/IPA
    
## Как запустить (веб-версия)

Чтобы протестировать офис в браузере:

1.  Клонируйте репозиторий: `git clone <ссылка>`.
2.  Запустите локальный сервер (обязательно для корректной работы модулей):
    ```bash
    npx serve
    ```
3.  Откройте полученный адрес в браузере. Рекомендуется использовать режим эмуляции мобильного устройства или тестировать на телефоне.
